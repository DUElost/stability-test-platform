## Alternatives

- **逐 issue 各开一个 PR**：本批 15 项全为文档/注释单点修正，拆成 15 个 PR 会连续占用 FIFO 队首
  （见 #1246/#1415 的排队阻塞经验），且易与并行会话在 DOC-MAP/ADR 等共享文件上反复冲突；改用
  单个 docs-sync PR，仍以 `Closes` 逐条关单。09-07 审计（PR #922）亦为同型合单。
- **ADR 版本 bump + 七挂靠位同步**（ADR-0029/0030/0031）：本批是事实性同步而非决策变更，且这三份
  ADR 头部状态行不携带 `Status（vX.Y）` 规范位版本，S12 不约束；照 `fix/1050-dle-spec-sync`（PR #1387）
  先例只改正文、不 bump，避免制造无决策内容的版本记录。
- **整篇重写 dated note / 设计文档**：保留历史与「实施前基线」是仓库惯例，只加状态与限定语。
- **批量改 DOC-MAP 的其他过期格**：仅改本次证据坐实的两格（AI 计划行的端点数与工具数），
  其余未经核对的枚举不动。
