  new-specialty-onboarding-runbook §4（前置条件行、发布规约块、4b REST 兜底轨标注
  **已失效**（行缺 `package_sha256` 在 strict 包核验下派发必败）、对账基准改 manifest+包）。
- **#3279（死指针三处 + 空转守卫）**：`.cursor/rules/agent-scripts.mdc` 与 `ruff.toml`
  注释改指 `check_tool_manifest.py`（append-only）+ `check_script_packages.py`（族树
  等价）；pre-commit 检查 4 从「版本目录 MD 拦截」（glob 0 命中、永久空转）改为
  **发布单元面改动 WARN 提示**（族树/manifest 暂存改动 → 打印登记/发布链指引）——
  硬门禁在 PR 侧（ci.yml 已接线），钩子层保留 ef8808e 类事故的秒级可见性，不再空转。
- **#3205（描述面 + 门禁机制）**：ADR-0051 §5 2b 行去掉「`agent-code` 排除
  `scripts/`」（归 Phase 3，v1.1 勘误口径）；D2 行补三口径标注（manifest 全集
  36 族 211 / 平台脚本 35 族 210 / 等价证明子集 208，注明时点）；`:9` 三时态与
  README 主表已被 v1.8 刷新顺带修掉（复核后不在本批重复动）。**机制面**：

  `**NNNN**（vN.M`——原正则对真看板行 0 命中，全体 ADR 的看板比对静默失明）+
  「看板行在场但 0 条目解析即红」失明下限；随即点亮并同步两条真漂移
  （0033 看板 v1.13≠头部 v1.15、0051 v1.5≠v1.8）。

## Alternatives

- **pre-commit 检查 4 直接移除**（issue 允许）：弃——ef8808e（ruff --fix 原地改写族树）
  形态的秒级现场提示仍有价值，WARN 不阻塞、硬执法留在 PR 门禁，职责分层清楚。
- **M7 看板行改写成完整形态以适配旧正则**：弃——整行几十个条目全量改写噪声大，
  且紧凑形态是看板的合理排版；让判据适配实存形态。
- **#3205 计数逐行改写历史基线数字**：弃——§1.3/§5 的 208/210 是历史时点值，
  改数字等于篡改记录；在 D2 落点补口径定义 + 要求报数带口径，消歧不改史。
- **4b REST 兜底轨整节删除**：弃——原文有 `content_sha256` 自算等契约细节，
  标注失效 + 留存历史成本最低；若确认无人回看可后续清。
