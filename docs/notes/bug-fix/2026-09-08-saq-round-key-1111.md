# 跨轮次 SAQ upload/merge key 隔离（#1111）

Status: implemented
Class: bug-fix

## Decision

增量与最终 `scan_task` 已用不同 key，但下游长期共用
`upload:{plan_run_id}` / `merge:{plan_run_id}`。SAQ 对同 key 在途任务
`enqueue` 返回 `None` 且不更新 kwargs，旧轮 merge 未结束时最终轮会被静默丢弃。

1. `_saq_round_key`：upload / merge / extract 带 `scan_round_id`（无 round 时
   回落旧形态）。
2. `_enqueue_or_raise`：`None` 视为去重失败，打 error 并抛错（可观测 + 可重试）。
3. 并发 merge 靠既有 `#1072` `merge_result/.stp_merge.lock` 串行化，不引入
   随机 key。

## Alternatives

- **固定 key + 待处理轮次队列**：需额外状态机，改动面更大。
- **随机 key**：易与 #1072 前的交叉收割叠加；否决。

## Revisit

若 extract 必须全局每 PlanRun 仅一次，可改回 `extract:{id}` 并在
merge 末尾 CAS；当前按轮次 extract 与增量报表一致。
