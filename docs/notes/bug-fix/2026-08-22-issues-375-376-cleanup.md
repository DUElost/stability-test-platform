# Issue #375/#376 清账：Notifications 弹窗迁 Radix + Dashboard 区块收口 + 颜色双源删除 + #343 迁移提示

Status: implemented
Class: bug-fix

来源：issue #375（triage 延后四项之三）+ #376（#343 行为注记两项）。

## Decision

- **P2-10**：Notifications 渠道/规则两个手写 `MODAL.overlay + panelLg`
  弹窗整体迁移为 `ui/dialog`（Radix）——统一 ESC / 焦点陷阱 / 遮罩
  点击关闭；表单体与 handler 原样保留。busy（actionLoading）时
  `onOpenChange` 拒绝关闭，与原行为一致。
- **P2-13**：①「在线率」独立 Card 从页面尾部移入「数据统计」区块、
  升格为带 CardTitle 的「主机在线率」卡（层级归位）；②三处错误
  路径的裸 Card 补 CardHeader/CardTitle（节点失败率排行/方案成功率
  排行/运行通过率趋势），错误态不再丢标题。**KPI `md:grid-cols-3`
  3+1 子项已不存在**——现状是 `grid-cols-2 lg:grid-cols-4`，判定
  已被后续轮修掉，无动作。
- **P3-17**：`colors.ts` 删除 `STATUS_BG_COLORS` 与 `BADGE_COLORS`
  （双源，零剩余消费者）；LiveConsole 状态条与 LoginPage 错误条
  改引 `tokens.STATUS_CHIP`（error→destructive 键名迁移）。
  LiveConsole RUNNING 顺势 primary→**warning**（#356/#374 的运行中
  琥珀统一补上最后一块）。
- **#376-1**：MapModelsDialog 预览中 unknown_models 从平文改为
  warning 色明示「应用会把 N 个当前 fleet 未见过的型号写入该项目
  match_models（不会被阻断）」。
- **#376-2**：①MapModelsDialog 预览 will_assign>0 时显示 warning 行
  「当前属 SEED/LEGACY 项目的设备不视为冲突，会直接迁入且不出现在
  冲突列表」；②AssignProjectDialog（设备批量归入）正文加常驻
  warning 提示块（同语义）。不阻断操作——后端行为符合设计，
  本轮只补「运维上易误判」的可见性。

## Alternatives

- **给 AssignProjectDialog 加后端预览（dry-run）**（否决）：#343 的
  bulk-project 无 preview 端点，加端点超出「UI 明示」的 issue 范围；
  常驻提示块已覆盖误判风险的主因（不知 SEED 不算冲突）。
- **保留 BADGE_COLORS 备用**（否决）：零消费者的死代码，与 #362
  双源清理方向相反。
