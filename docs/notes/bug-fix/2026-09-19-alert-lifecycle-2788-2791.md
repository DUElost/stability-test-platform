# 告警生命周期两处：站点子集无生产者规则 + 退役 host 指标 series 不清理（#2788 / #2791）

Status: implemented
Class: bug-fix

## Decision

1. **#2788（站点装了无生产者的规则）**：把 `StabilityPgSchemaGuessing` 从
   `deploy/prometheus/site-alerts.yml` **移除**（平台文件 `alerts-stability-platform.yml`
   保留该规则，控制面挂载路径承载）——`stp-pg-guard` 读 PG 服务日志，而 PG 只在控制面
   宿主上，站点装了也扫不到；规则里的 `absent(stp_pg_guard_last_run)` 分支让站点 Prometheus
   **永久 firing**。同批修正两处错误表述：`docs/operations/installation.md` 的 S4 不再声称
   随站点安装面落地该采集器；`deploy/control-plane/systemd/stp-pg-guard.service` 的文件头
   从「Rendered by the site installer」改为「控制面宿主单元、不在站点安装清单」。
   判据侧补第三根钉子：**textfile 生产者必须在站点安装清单里**（新增
   `site_textfile_metric_index()` + `_PRODUCER_SITE_UNIT` 登记表 + `MONITORING_SAMPLER`
   单元名解析；未登记的生产者即红），并把 `inert_rules_at_site` 的谓词从「引用了控制面注册表
   指标」一般化为「引用了站点可见面之外的指标」——这样「仓库有生产者、站点不装那个单元」
   的形态（#2788 的成因）也进 inert 对拍。`tests/metrics_registry.py` 抽出
   `textfile_metrics_for(rel)` 支持按文件取指标名（原函数改为其聚合）。
2. **#2791（退役 host 的 series 永驻）**：`_refresh_host_device_adb_gauges` 增**差集清理**——
   维护本进程已暴露的 host_id 集合，每轮对 `已暴露 - 在册` 的 host 逐桶
   `host_device_adb_state.remove(host_id, bucket)` 并把集合收敛到在册面。修复前只刷新在册
   host，退役 host（先 live、后退役）的 label child 常驻 registry，`offline` 计数冻结在
   故障值，被 `StabilityHostAdbOfflineConcentration`（表达式无 liveness 门）15m 起永久 firing，
   基数也随机器轮换单调增长。函数文档串的「退役 host 不进指标」不再是纸面不变量。

## Alternatives

- **#2788 给站点补装 `stp-pg-guard`**：弃——站点宿主没有 PG 服务日志，探针恒报
  「无指纹 + last_run 有值」，把「结构性无样本」换成「结构性恒零」，仍是假信号；且
  安装面扩大与 #2643 方向 1（站点只装站点可见面）相反。
- **#2788 让 installer 条件安装该单元**：弃——ADR-0044 的站点模型里 PG 属于控制面，
  没有「这个站点也跑 PG」的合法形态；等真出现多站点共库形态再议（Revisit）。
- **#2788 只删规则、不加判据**：弃——这正是 #2643 关单时「债务清单已清零」被推翻的
  直接原因（对拍绿而事实红）。判据按安装清单过滤，才能让同一形态下次在 CI 红。
- **#2791 遍历 `Gauge._metrics` 私有字典逐个删**：弃——依赖 prometheus_client 私有结构；
  用「已暴露集合」自持状态，语义等价且不碰私有 API。
- **#2791 每轮先 `clear()` 再重填**：弃——抓取期间会出现空窗（Prometheus 抓到空样本），
  且并发抓取会互相踩；差集 remove 无空窗。

## Revisit

- #2788 的 `_PRODUCER_SITE_UNIT`：新增 textfile 生产者时必须登记；若将来出现「站点也跑
  PG」或「多站点共库」形态，重新裁决 `stp-pg-guard` 的安装面，而不是把它默认加进清单。
- #2791 的差集清理只覆盖 adb_state 这一组 gauge；若将来再引入 per-host 动态 label 的
  gauge（如按 host 的设备详情），必须同样带差集清理，否则同类「退役后永驻」会复现。
