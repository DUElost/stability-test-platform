# S12 表格形态收口：tip 锚「版本」列 + 反向检查 + ADR-0031 补版本（#2304）

Status: implemented
Class: bug-fix

## Decision

四件事同批，都在 `tools/dev/check_governance_surface.py` 与两篇 ADR 索引面：

**① 表格 token 锚「版本」列。** 新增 `_revision_table_version_tokens()`：先按表头定位
`版本` 列（三种列布局：`版本|日期|变更` / `日期|版本|内容` / 无版本列），只取该列 token；
无版本列者（ADR-0026/0027）退回「cell 行首 token」——ADR-0027 每个变更 cell 以
`vX.Y（…）：` 开头，实测仍取全 1.1–1.7。

**② 让该条对表格 ADR 生效。** `parse_adr_record_tip()` 由「只读项目符块」改为
`_record_version_tokens() + _revision_table_version_tokens()` 取版本号最大者。此前
6 篇表格 ADR（0026/0029/0030/0031/0032/0033）的「头部 ↔ 最新版本」比对**结构性休眠**
（`record_tip` 恒为 `None`）；ADR-0027 是例外（另有单行 `- 版本记录：`）。

**③ 新增反向检查** `check_adr_head_version_present()`：**索引面带规范位版本而头部没有**
即报。此前 S12 只查「头部有版本时索引面是否跟上」——反向不查，于是 README 的版本前缀
在头部无版本时是**无权威可比的孤值**。收口二选一：补头部版本，或去掉索引前缀。

**④ 同批收口 ADR-0031**（反向检查的首个也是唯一的现实例）：头部补 `v1.7`（其修订记录
最新版，与表格 max 一致），README 主表前缀 `v1.5` → `v1.7` 并把摘要补到 v1.6/v1.7
（原文只写到 v1.5）。

**⑤ S14 集合同步锚列位**：`parse_adr_record_versions()` 的表格部分改用同一函数。这既是
一致性，也是**修正**——整章扫描会把**正文列**里的跨 ADR 引用算成自己的版本：ADR-0030 的
v1.1 行写着「（对齐 ADR-0029 v2.3.1 教训）」，整章扫描得到 `2.3`，既让 tip 判成 v2.3
（假红），又让伪造引用 `ADR-0030 v2.3` 通过集合判据。

实测锚列位的影响**只有这一个 token**：其余 6 篇表格 ADR 的集合与整章扫描完全一致
（零损失、纯去污染）。

## Alternatives

- **A. 维持整章取 token**：否决（②⑤ 的实现依据）。ADR-0030 假红即由此而来——见
  [`2026-09-16-adr-canonical-version-heads-2250.md`](2026-09-16-adr-canonical-version-heads-2250.md)
  §Revisit ①②的实测。
- **B. 不锚列位，改为「排除含 `ADR-` 字样的 cell」**：否决。脆弱——跨 ADR 引用未必带
  `ADR-` 前缀（「对齐 §9 v2.3」「见上一版 v2.3」都会漏网）；列位是**结构事实**，语义过滤
  不是。
- **C. 反向检查做 advisory 而非 BLOCK**：否决。与 #1524（头部状态行须在场）、#2035
  （索引行状态 cell 须可解析）同纪律：同一「静默跳过」族，取阻塞；且落地时存量仅
  ADR-0031 一处，已同批收口，无存量背书问题。
- **D. ADR-0031 反向收口走「删 README 版本前缀」**：否决。README 的 `v1.5` 携带信息
  （该行摘要描述的版本），删前缀丢事实；补头部版本更符合「头部是权威面」的既有模型，
  且顺带使该 ADR 的该条比对从此生效。
- **E. 顺带归一 ADR-0031 的 M7 / DOC-MAP 面**：不做。该 ADR 两者都不在约束形态内
  （M7 条目写 `**Accepted**：…` 无版本 token、DOC-MAP 无该行），归一属于扩大 diff，
  记入 Revisit。

## Revisit

- **ADR-0044 是另一种休眠**：头部有规范位版本 `v1.0`，但**没有任何版本记录**（项目符块与
  表格都没有）→ `record_tip=None` → 该条不约束。与 #2304 的表格休眠不同因（无记录可比，
  非解析不到）。若将来给它补版本记录块，该条才会生效。
- **表格区间未展开**：`v0.1–v0.4.1` 只取到两端字面 token（0.1 与 0.4），引用
  v0.2/v0.3/v0.4.1 仍会误报（当前无此类引用）。出口：区间展开，或表格里逐行列出。
- **锚列位依赖表头列名**：当前判据是「表头存在 `| 版本 |` 单元格」。若将来有 ADR 用别的
  列名（`| v |` / `| Ver |`），会静默退回 cell 行首判定（行为可能不同）——届时要么扩列名
  集合，要么在 ADR 模板里钉死列名。
- **M7 / DOC-MAP 的形态盲区仍在**：`_ADR_M7_ENTRY` 只认 `ADR-00XX（**Status** vX.Y）`，
  ADR-0029/0031 的 M7 条目是别的形态 → 不受约束；DOC-MAP 无该行时同样不约束。
- **反向检查对「正当删除头部版本」会报**：若某 ADR 要撤回版本语义，需同时去掉索引面的
  版本前缀（报错信息里已写明这条出口）。
