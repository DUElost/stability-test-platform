# memory_lint 断链误报：含全角标点的示例片段不再当路径候选（#2552）

Status: implemented
Class: bug-fix

## Decision

`_is_candidate_path` 增加一条判据：**token 含全角标点即不是路径候选**（`。，、：；？！（）【】「」『』·—…《》〈〉`）。
仓库路径里不可能出现全角标点，而中文笔记的「示例片段」常带全角句读——实测形态：

```
例如被切成了路径 `docs/DOC-MAP.md。Cursor`。
```

该 token 以仓库前缀 `docs/` 开头 ⇒ 基线判为候选 ⇒ 存在性检查失败 ⇒ **ERROR 断链**。
与既有 `_PLACEHOLDER_MARKERS`（`...`/`<`/`*` 等）放在同一层：都是「这类 token 根本
不构成可判定的路径」。

## Alternatives

- **A. 只修记忆库里的那条笔记**：治标。误报形态由「中文行内反引号 + 示例片段」决定，
  任何人写带示例的笔记都会再命中；而且它报在 **ERROR** 级，会把真断链淹掉
  （#2520 同一主题：信号质量）。
- **B. 把这类情况降为 WARN**：不准确。含全角标点的 token 不是「环境可能迁移」那类
  可疑引用，而是**语法上不可能是路径**；降级会留下噪音（本工具已在 18 条 WARN 上）。
- **C. 解析反引号内的语义（区分「引用」与「示例」）**：做不到且不必要——标点判据已经
  精确切开这两类。

  第 3 例（正常路径仍是候选）在基线上也绿 = 钉住**未放宽**的一面。修复后 48 passed。

  前 5 条里 4 条是真引用问题（已在记忆库侧修正：跨仓路径 / 本机文件 / 分支名各一 + 一行超宽），
  第 5 条即本单修的误报。

## Revisit

- **剩余 18 条 WARN**：全是「绝对路径引用不存在」（`/api/v1/...` 这类**接口路径**被当文件、
  `/opt/...` 主机路径）。它们已在 WARN 级且文案写明「环境可能迁移」，暂不动；若这类噪音
  继续增长，可再引入一条判据（例如 `/api/` 前缀或「出现在反引号里且以 `/` 开头但不是
  文件形态」），但要先有统计再定阈值。
- **记忆库的另外 4 条**：跨仓路径与本机文件我改成了「非仓库内」的显式措辞（避免下次又被
  当路径），分支名去掉了反引号。若将来工具支持「外部引用」标记（例如 `ext:` 前缀），
  这些可以写回结构化形态。
