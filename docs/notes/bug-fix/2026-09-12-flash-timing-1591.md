# 刷机时序加固：fingerprint 就绪等待 + 失败恢复 + oobe 验证重试（#1591）

Status: implemented
Class: bug-fix

## Decision

ADR-0020：已发布版本目录不可原地修改。本 PR 最初误改 `flash_firmware
v1.3.12` / `oobe_skip v1.1.1`（及嵌套拷贝旧版本），lint 门禁失败。

纠正为新建版本（行为变更、`default_params` 不变 → 无需 seed，与 #811
v1.3.13 同口径，扫描自动建行）：

- `flash_firmware/v1.3.14`（基于 v1.3.13 全量副本）：
  - `_wait_model_ready`：读 `ro.product.model` 前轮询 model 非空（默认 90s，
    `model_ready_wait_seconds` 可调）——修刷机成功但 fingerprint 误判；
  - `_attempt_device_recovery`：flash 失败后 `adb reboot`——减少 BROM/USB 死态。
- `oobe_skip/v1.1.2`（基于 v1.1.1 全量副本）：`verify_retries`（默认 2）——
  验证失败后重设 flags + 等待 + 重验证。

已发布目录 `v1.3.12` / `v1.1.1` 恢复为与 `origin/main` 字节一致；误嵌套的
`v1.3.12/v1.3.11/`、`v1.1.1/v1.1.0/` 删除；错误 seed
`x3y2z1a0b9c8`（对已存在版本写 sha）移除。

## Alternatives

- 原地改 v1.3.12 / v1.1.1——违反 ADR-0020，CI
  `check-script-version-immutability` 必拦，且会造成 `content_sha256`
  与磁盘永久失配。
- 弱化 / 跳过不可变门禁——不可接受；门禁是 precheck 契约的防线。
- 保留 seed 迁移写 v1.3.14/v1.1.2——纯行为变更无参数变化时与 #811 口径
  不一致；扫描即可建行。

## Verification

- `python tools/dev/check-script-version-immutability.py --base origin/main`
  通过（无已发布版本被改）。
- `backend/agent/tests/test_device_flash_scripts.py`：新版本含
  `_wait_model_ready` / `_attempt_device_recovery` / `verify_retries`。
- 已发布 `v1.3.12` / `v1.1.1` 与 `origin/main` 一致。
