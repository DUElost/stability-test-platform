# 观测面三单：整窗 0 完成信号 + recycler 截止行收口 + 链级断链可见性（#3077 / #3341 / #3066 A半）

Status: implemented
Class: bug-fix

## Decision

批2 观测面（owner 2026-09-26 sweep + tier-B 裁决）三单一次交付，全部落在 ADR-0048
允许面内（只观测，不改判定轴、不改 plan_run.status、续链语义不变）：

- **#3341 代码半**（recycler `_fill_deferred_post_completions`）：截止界
  （grace + max_defer）前移到查询之前，超窗行 **SQL 层排除**——原实现先
  `LIMIT 10` 再 Python 层过滤，截止行占满名额饿死补偿通道（#3341 正文实锤的
  饿死面）；主查询补 `ORDER BY ended_at` 取最老优先。截止行单独取回经
  `case_result_ingest_pending` 复核：detail 已可读＝主路径漏发，照常重入队
  （enqueue 同 key 去重兜住重复）；确实不可读才真正截止，ERROR 日志只写已核实
  原因（原文案「detail 长期未达」把推断写成事实）。行数导新 gauge
  `stability_post_completion_cutoff_jobs`。一次性恢复半（6 job）已于 09-26
  由有生产权限者闭环，本 PR 只收代码半。
- **#3077**（`plan_run_finalization.announce_parent_terminal` 公共咽喉）：
  run 终态且 `total_job_count ≥ 20 && completed_job_count == 0` → counter
  `stability_plan_run_zero_output_total{level="warning"}`；同 plan 上一条终态
  run 同样零产出（独立短会话查证已提交世界）升 `critical`。N=20 取 owner
  sweep 正文判据（排除单设备 smoke 形态），上线满 30 天回看（常量
  `ZERO_OUTPUT_MIN_JOBS` 便于微调）。abort / 聚合 / 补偿重放三条终态路径经
  同一咽喉全覆盖。
- **#3066 A半**（`plan_chain_trigger`）：链停本段且下游段未创建 → counter
  `stability_plan_chain_visibility_gap_total{reason}` + `CHAIN_INCOMPLETE`
  warning 级事件（EventType 新成员）。三个静默断链点接线：
  ① FAILED 父段（announce 咽喉 Hook A——reconciler 只重试 SUCCESS/PARTIAL，
  FAILED 断链原本完全无信号）；② no-devices 健康门筛空（trigger async/sync）；
  ③ 派发失败未落子行（rollback helper async/sync）。去重标记
  `run_context.chain_visibility_gap_signaled` 每 parent 一次，随调用方既有
  提交落库。缺失段数 = 期望段数（快照优先沿 next_plan_id 遍历，深度帽 20 与
  读路径 MAX_CHAIN_DEPTH 同源）− 本链已落库后续 run 数。

告警面：4 条新规则（StabilityPlanRunZeroOutput / StabilityPlanRunZeroOutputConsecutive /
StabilityPlanChainIncomplete / StabilityPostCompletionCutoffJobs）+ promtool
场景全覆盖（每规则必有场景守卫）。

## Alternatives

- #3341 仅 Python 层过滤＋告警：裁决明说 SQL 层排除（占名额是根因），不取。
- #3077 落 gauge per plan：plan_id 标签基数无界；counter+level 词表与全文件
  increase()>0 告警风格一致，细节留日志与事件。
- #3066① 从 reconciler 扫全链：扫描面大且与每 tick 语义纠缠；在既有静默点
  就地发射更小且覆盖同一事实。reconciler 永远不重试 FAILED 父段 → Hook A
  必须挂在 announce 咽喉而非 trigger 内部。
- 事件走 socketio 直发：通知通道已有 SAQ 投递 + 幂等（#1167），不另起一路。
