# Agent Note: Fix `oobe_skip@1.1.3` adb root invocation, Tinno FactoryOOBE clearing, and multi-display focus detection (#4083)

Status: implemented
Class: bug-fix

## Decision

修复 `backend/agent/scripts/oobe_skip/oobe_skip.py` 并登记发布为 `1.1.3`（同步将 `flash_unisoc.json` 与 `flash_unisoc_bsl.json` 模板 pin 升至 `1.1.3`）：

1. **修复 `adb root` 与 `_wait_adbd_ready` 调用形式**：
   - 新增 `_adb_cmd(serial, adb_path, adb_args)` 直调 `adb -s <serial> <args...>`；将原 `_adb_shell(..., ["root"])`（`adb shell root`，实测 `rc=127`）与 `_wait_adbd_ready` 中的 `_adb_shell(..., ["get-state"])` 改为 `_adb_cmd(..., ["root"])` 与 `_adb_cmd(..., ["get-state"])`。
2. **补齐 `setup_skipped=1`、多向导包清场与禁用持久化**：
   - 写入 `settings put secure setup_skipped 1`；
   - 默认同时处理主向导包 `com.google.android.setupwizard` 与 `com.tinno.factoryoobe`（支持 `extra_setupwizard_packages` 覆盖）：执行 `am force-stop <pkg>` 并按 `disable_setupwizard`（默认 `true`）执行 best-effort `pm disable-user --user 0 <pkg>`，防止重启或广播再次拉起 SetupWizard 后重置 `user_setup_complete=0` / `device_provisioned=0`。
3. **修复多屏 `mCurrentFocus=null` 误判与向导残留补清**：
   - 新增 `_extract_current_focus()` 跳过副屏/虚拟屏的 `mCurrentFocus=null`，取真实非空焦点窗口并同时匹配主/额外向导包；
   - 若清场后首次读取焦点仍停留在向导窗口，等待 3s 执行一次补清场与重检。

## Alternatives

- **仅修改 `adb root` 而不禁用 SetupWizard 组件**：否决；实机（串号 `AUXMNX69****0119`，已脱敏）已验证在未禁用向导组件时，一次重启即会由 `SetupWizard` 将 `user_setup_complete` 与 `device_provisioned` 写回 `0` 并重新进入 `WelcomeActivity`。
- **对所有非空焦点仍在 SUW 的场景直接判脚本失败**：保留 v1.1.0 契约（标志位是权威判据、`ui_focus` 留痕不误杀合法过渡态），但在检测到仍停在向导时先自动补清一次。
