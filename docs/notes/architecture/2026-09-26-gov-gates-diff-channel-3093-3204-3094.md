## Alternatives

- **日期判据「替换」vs「叠加」**：裁决要求 PR 通道「不再读自填日期」。实现为 diff 通道
  （权威）+ 日期通道保留（无 base 时的近似，且对「修改既有 ≥cutoff ADR 删归属域」仍有
  覆盖，diff-only 会漏这一形态）。日期通道在 diff 可得时不再承载「新建」判定，逃逸面
  （伪造日期的新文件）已由 diff 通道闭合。
- **diff 端点 `mb..HEAD` vs `mb → 工作树`**：后者让本地 gate 覆盖未提交变更（与既有
  磁盘读面语义一致）；CI 干净检出时二者等价。实测 `mb..HEAD` 形态下未提交 bump 不进
  判定集（红向验证时发现），故改工作树端点。未跟踪新文件不入 git diff，由日期通道兜底，
  CI（全部已跟踪）无此缺口。
- **gate key 改名 vs 只改 ci.yml step 名**：run_gates 输出 `== tool-contract ==` 同样会被
  读成「已验真实工具契约」，故 key 一并改为 `tool-contract-fixture`；涟漪 = run_gates 三处
  + S5x 锚点 + 守卫测试，全部在本批射程内。
