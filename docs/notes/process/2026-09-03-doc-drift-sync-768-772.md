# 09-01 审计文档漂移同步（DEGRADED / #220-UNISOC / #506 / params / NFS merge）

Status: implemented
Class: process

## Decision

把 2026-09-01 七日审计（以及收口复核）确认的常驻文档漂移一次性修齐，
全部改动仅来自代码/迁移/提交可直接核对的证据，不夹带推测：

- **DEGRADED 残留**（#768）：PlanRun 的 `DEGRADED` 已随 #417 从枚举与 DB
  enum label 删除（迁移 `w9x0y1z2a3b4`），但 CLAUDE.md、ADR-0020/21/25/26、
  `docs/design/01/05/06/07`、log-flow 时序表共 12 处仍写「仅历史可读 /
  FAILED/DEGRADED」。全部改为现状口径。ADR-0026 的「现状（已核实）」句改
  「决策基线（撰写时已核实）」并删除失效行号引用（`enums.py:13-18` 等）——
  ADR 是决策记录，不改历史立场，只改误导性的现状态述。host 健康状态与
  WatcherPolicy 的 DEGRADED 仍有效，未动。
- **#220 只扫 MTK 失效**（#769）：`STP_WATCHER_AEE_RECONCILE_PLATFORMS` 白名单
  键随 ADR-0032 P1（`922049d2`）删除、全代码零读取点；平台路由改为按
  `device.platform` 选 Reconciler（UNISOC → `UnisocUniviewReconciler` 真实现、
  QCOM → 跳过）。AGENTS.md 子系统细则、`backend/agent/aee/CLAUDE.md` 平台门禁
  节、`backend/agent/.env.example` 死键条目同步为平台路由口径；后者顺带补上
  此前零文档的 `STP_WATCHER_UNISOC_RECONCILE_INTERVAL_SECONDS=180` /
  `_MAX_TICK_ERRORS=5` 两键。
- **#506 尚未实现**（#770）：AGENTS.md 退役口径改为指向已落地的脚本管理页
  「使用统计（近 30 天）」与 `GET /scripts/{id}/usage`（PR #572/#615）。
- **WiFi 是唯一特例**（#771）：params 打破 `default_params` 的注入实为三处——
  #508 步骤级 `step.params`、WiFi 注入、ADR-0030 §3.4 mtbf 套件注入
  （`inject_suite_params`）；CLAUDE.md 与完整链路行同步。
- **NFS 表缺 merge/**（#772）：AGENTS.md 路径表 dedup 行补 merge 中心化发布
  子目录（`{root}/dedup/{run_id}/merge/`，`dedup_scan.py` 中心化发布，2026-08-31）。

影响面：AGENTS.md / CLAUDE.md / README.md / `backend/agent/aee/CLAUDE.md` /
`backend/agent/.env.example` / ADR-0020/21/25/26 / `docs/design/01/05/06/07` /
`docs/design/2026-adr-0025-log-flow-sequence.md`（14 文件，仅文档与 env
示例注释，无代码变更）。`docs/archive/`、带日期的 point-in-time 设计稿与
reviews/ 属历史记录，不动。

## Alternatives

- 保留「仅历史可读」写法等新状态机叙事——被否：与 `state_machine.py` 现值
  直接矛盾，会误导后继改动者。
- 在 ADR-0026 里改写成「现状已含 QUEUED/PRECHECK」——被否：ADR 是目标态
  决策记录，现状演进已有独立提交（`7344def5` legacy 双轨移除），ADR 只
  需要不再宣称错误的现状；准入队列 V2 现状落在 CLAUDE.md 与 design/07。

## Verification

- 修改后复扫 12 个常驻文档：DEGRADED 仅剩 ADR-0026 决策基线处的有意叙述与
  host/WatcherPolicy 有效引用；`STP_WATCHER_AEE_RECONCILE_PLATFORMS` 仅剩
  「已删除」说明。
- 每条改动均对到代码符号：`enums.py` / `state_machine.py` /
  `precheck/runner.py:retry_plan_run_dispatch` / `job_session.py`
  `_resolve_reconciler_class` / `aee/collectors/unisoc.py` /
  `unisoc_reconciler.py` / `plan_dispatcher_core.py`（#508 合并 + WiFi +
  `inject_suite_params`）/ `dedup_scan.py:699`（merge 中心化）。
- 纯文档与环境示例注释变更，不触发后端/前端测试；由 CI lint 门禁兜底。
