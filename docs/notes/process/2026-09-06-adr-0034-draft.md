- **方案基础**：09-05 多 Harness 方案（Registry/ai_work.py，Phase 0-4）+ 审查 6 修正全部固化进 §2（supersede+diff 优先 / 等集成非终态 / TTL 心跳 / registry 落 worktree 外+gitignore / 保留并发上限 / P3=drift gate 非 merge queue）；
- **G2 由条件采纳升格为本 ADR 内裁决（§3）**：09-06 嵌套 AGENTS.md 实测矩阵（Codex/Cursor/OpenCode 3/3 live 通过、Claude 实证只走 CLAUDE.md 通道）消除了原「实施前先实测」的条件性；形态定「真身+薄壳」，**优先级 symlink > @import**（依据 #857：@import 子目录不解析，双模式实证）；
- **G5 不做决定**，Revisit 节触发声明；**#855** 在 Verification 节收口（合入即满足主触发，三选一方向 P1 实施期裁决）；
- 取代对象显式声明：2026-09-04-multi-agent-parallel-convention.md（Accepted 后由 P0 PR 标注 superseded，本文不提前改动它）；
- 待确认三点的落法（用户 09-06 批准按建议执行）：阶段沿用 Phase 0-4 粒度；G2 升格为 ADR 内工作项；#855 只锁触发与候选。

**v0.2 评审修订（同日，用户评审意见）**：①§2.1 增「选择权原则」——Harness 选择始终由开发者决定，契约不含需求路由/自动下发；箭头链只表溯源不表指派，Registry 是自声明登记簿非调度器（消除「Requirement → Harness」被误读为流水线的歧义）；②§2.7 P2 明示 Adapter 为「上下文供给，非路由」；③P0 补明 harness-adapters.md 与基线 note 的并行约定指针接线（基线 note Revisit 既定要求，v0.1 漏列）。与 #853 基线 note 的交接条款复核吻合：基线「不引入 Role/Scope/Registry 直至后续 ADR 正式取代」↔ 本文即被指定的后续 ADR，Accepted 前现行约定不变。

**v0.3 Contract hardening（同日，用户对照冻结版 Contract v1 的逐项评审：架构 ~90% 对齐，做精确加固而非架构改造）**——六项必修：①§2.2 registry root 改为 `$(git rev-parse --git-common-dir)/ai-work/`（多 worktree 经 common dir 解析到同一位置，替代「主 checkout 固定绝对路径」；.git 内天然免 gitignore）+ 锁文件固定 `registry.lock` 同目录；②§2.3 状态模型改 **liveness×integration 两维正交**，overlap 集合 = integration∈{NO_PR,PR_OPEN,READY} 且 liveness 不参与（修正「仅 ACTIVE 参与」的语义错误——finish 后 STALE 的在途 PR 仍是集成风险窗口）；③STALE 永远 advisory、不退出集成窗口（随②）；④§2.5 TTL 分期——P1 无 heartbeat daemon 故仅 advisory 不改语义，P2 有 heartbeat 后 last_seen 方可升格；⑤§2.3 事实来源分层——**MERGED 只能由 GitHub PR 状态确认**，`finish` 语义仅为「停止编码且已开 PR」，ai_work 不得单方面写终态；⑥registry.lock+same-dir 原子替换细节固化。三项 Contract 完善：⑦§2.10 `docs/development/ai/execution-contract.md` 为 Execution Contract 唯一权威源（ADR=方向裁决记录，AGENTS.md=minimal bootstrap 不空壳化）；⑧§2.9 `test_impact{none,direct,indirect}` 声明 × CI 证据 → coverage-mismatch advisory（Contract 先定义、实现后置 P3）；⑨§2.8 Scope MVP=repo-relative file/directory 归一化，不支持 glob/ownership/拆分/semantic/locking，**Role 不是文件 ownership 边界**。Alternatives 补两行否决记录（overlap 仅看 ACTIVE / P1 即硬 TTL）。

**v0.4 多 Harness 评审综合修订（同日晚，八源只读审查 → `docs/reviews/REVIEW_ADR0034_MULTI_HARNESS_2026-09-06_synthesis.md`，R 编号权威映射）**：采纳 21 项——R1 registry root 固定 `--path-format=absolute` 唯一发现方式（6 源实测共振）+删外置替代落点；R2/R6 状态模型升三维 `lifecycle{CODING,FINISHED,ABANDONED}×liveness{LIVE,STALE 派生不持久化}×integration{…,MERGED,CLOSED}`（READY=GitHub checks 派生刷新可回退、CLOSED=PR 关未合、ABANDONED 仅显式人工、finish 只写 lifecycle 解耦 PR 先后）；R4 `status` 严格只读；R5 **overlap 数据源=declared∪derived(diff) 以 derived 为准**（09-04 声明≠diff 实测反例入文）；R7 原子写九步全序（validate+父目录 fsync）；R8「五处 canonical」→「单一 Contract+列举薄入口」；R9 P0 细则一次性平移、ADR §2 收缩；R10 P0 补 repository-workflow.md 接线；R11 execution-contract.md 入 S2/S6；R12 test_impact P1 允许缺省=indirect（否决推迟 P3）；R13 coverage-mismatch 证据口径=夜间全量/合并后记录；R14 文档同步族（README 主表补行/DOC-MAP/governance 文档 S1–S11/本 note 锚定/aee 路径/术语）；R15 S11 归因修正（#856）；R16 drift 豁免入 contract 初稿；R17 scope 拒绝规则（absolute/../symlink escape/组件边界）；R19 G2 补 symlink 方向 CLAUDE→AGENTS+写入防护+验收含根契约双边可见；R20 #855 三段触发；R21 #847 对账+Alternatives 窄口径+审阅瓶颈正面回应；R22 P1 启动判据。范围外遗留 3 项（step-stall 文档过期/effective_slots 出处/AGENT_SECRET 告警）记 synthesis 附录 B。

**裁决落地（同日更晚，用户修订 9261bd 后的同步 PR）**：R6/R18 两项人工裁决收口——①冻结版 Contract v1 确认为**两维**（Execution × Integration），三维模型为评审建议而非冻结条款；B3 真实阻断点收窄为「finish 缺独立可持久化语义表达」，lifecycle 与 `finished_at` 二选一皆合规，**v0.4 的 lifecycle 字段属合规实现选择**（兼载 ABANDONED 放弃语义），ADR §2.3 补「裁决背景」句注明；②R18 Competition mode 冻结版不含，降为非阻断追溯建议不入 Contract，ADR Revisit 改「已裁决」。synthesis R6/R18 裁决栏与文首「裁决后补记」同步更新；用户修订后的 9261bd 原文随本 PR 入库。

## Alternatives

- **先写 P0 规则 PR 再写 ADR**——放弃：AGENTS.md 自述「改变现行执行语义前必须先由 ADR 正式裁决」，顺序不可倒置。
- **在本文中直接改写 AGENTS.md/2026-09-04 note**——放弃：P0 明确走独立 docs PR（元文件串行化），本文只立契约。
- **G2 形态裁死 symlink 单选**——放弃：symlink 有 Windows 协作/工具链兼容风险未验证，保留 import 退路并绑定 #857 修复前置更稳健。
- **把 #855 三选一在本文裁死**——放弃：方向选择依赖 P1 实施期的新信息（drift gate 实际形态），过早裁死会迫使返工。
