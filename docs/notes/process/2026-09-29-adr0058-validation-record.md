## Decision

**本 note 不修改 ADR-0058、`batch-planning.md` 或任何权威流程文档。** 它分三层，三层互不渗透：

| 层 | 内容 | 效力 |

| 规则层 | ADR-0058、`batch-planning.md`、`batch-review.md` | 由正式修订 PR 变更；实验结果若支持推广，另行提出修订，不在本 note 内生效 |

**确认状态：Owner 已确认。** Owner 于 2026-09-29 在 #3533 上按 head `d3c3eccd` 的版本确认登记 B3 验证方案：[确认记录](https://github.com/DUElost/stability-test-platform/pull/3533#issuecomment-5890447469)。较早的口头同意不适用于本版（H1–H5 在 Codex 复核后已被实质重写），以上述书面记录为准。

确认的范围仅限于：接受本 note 作为后续验证实验的登记方案。它**不**表示 ADR-0058 已被验证或任何假设成立；阈值仍没有经验依据；不自动授权 B3 之后的任何实验批次；B3 的载体 issue、范围与 Appetite 另行裁决。

B1 + B2 足以说明这套流程**能跑通**，并对其中几条机制给出了**正向信号**；
**不足以**证明 ADR-0058 正确。

### 7. 混杂与局限

1. 没有对照组：不知道同样的问题走原流程会漏多少，也不知道 flash 模型没有方案时会差多少；
2. 没有结果指标：ADR §5 要求 B2 关单记录「退回次数及根因、复核前合入次数、激活到关单时长」，
   #3497 的关单评论里没有这几项，§3 是事后从评论与 PR 记录整理的；部署后的返工率、回归率、Owner 花费的时间**都没有**；
3. B2 修的是实例，没有加机械守卫（方案 §6 明确不抽公共组件；只有 G7 加了一条跨语言守卫），
   所以 D4「收口后不再回流」这部分要几周后才有数据；
4. #3502（v1.2）、#3490、#3492 三个 ADR 相关 PR 在一天内合入，说明文档本身也出现过
   需要外部复核才能发现的残留（ADR-0034 §2.6 漏改一句）；
5. **B3 会被刻意选成困难样本**（见 §Verification 的选批规则）：它是压力测试，不是典型批次。因此 B3 的结果
   只能回答「流程在困难情形下是否成立」，**不能外推**——B3 发现复核很有价值，不能据此推出普通批次也应扩大复核；
   B3 周期变长，也不能据此否定 ADR。要外推到普通批次，需要另有一个普通批次的数据；
6. **净收益无法在现有样本上检验**：复核的成本（时间、周期增加、无效退回）没有历史数据，也没有对照组，
   所以本 note 只讨论复核的「独立发现能力」，不讨论「净收益」。

### 8. 数据露出的缺口：规划阶段出现集中缺陷

规划缺陷 B1 有 5 处、B2 在派单前又被方案复核找出 5 处，还有 1 处漏过（提示词失效）。
而 ADR-0058 只要求复核 **PR**，不要求复核**方案**；复核者的问题 A 只核对「是否符合方案」。
这是 n = 2 的观察，**不是结论**（例如不能据此说规划阶段就是各环节中最弱的一环——其他环节的缺陷有没有被同样充分地发现，本 note 没有数据）；
也不据此修改 ADR；是否在 B3 里作为受控变量检验，由 Owner 授权（见 H4）。

## Alternatives

- **直接宣布验证通过**：否。样本量、偏差、缺失指标都不允许；
- **立即在 ADR 里补「方案复核」条款**：否。证据只有 B2 一次，先受控验证；
- **回溯对比过去的局部修复做对照**：只作旁证（§5）。历史修复的问题、人员、时期都不可比，不作为判据；
- **规划者自己出评估结论**：否。规划者是被评估对象之一，B3 结束后的评估应由复核工作面独立执行，规划者只提供数据；
- **把记录项写成对所有批次的「关单时必须填写、缺项视为未完成」**：否。这会与 ADR-0058 D9（长期数据不作关单前置）冲突，
  而且「4 周内返工」在时间上不可能在关单时填写；本版把记录项限定在 B3 实验，并拆成「关单时」与「T+4 周」两类；
- **把 Owner 的口头同意直接写成「已确认」并转 implemented**：否。没有可追溯记录，且假设已被重写。

### 复查用扫描脚本（H1a / H1b 基线）

在仓库根目录运行；它只数「赋值式 `useQuery` 里没有引用 `isError / error` 的调用点」，
**不判断失败时用户看到什么**——那一步需要人工逐个看渲染。

```python
import re, glob
rows = []
for f in sorted(glob.glob('frontend/src/**/*.tsx', recursive=True)):
    if '.test.' in f:
        continue
    s = open(f, encoding='utf-8').read()
    for m in re.finditer(r'const\s+(\{[^}]*\}|\w+)\s*=\s*useQuery\s*\(', s):
        lhs = m.group(1)
        if lhs.startswith('{'):
            handled = bool(re.search(r'\b(isError|error)\b', lhs))
        else:
            handled = bool(re.search(r'\b%s\.(isError|error|isLoadingError|status)\b' % re.escape(lhs), s))
        rows.append((f, s.count('\n', 0, m.start()) + 1, lhs.replace('\n', ' ')[:40], handled))
un = [r for r in rows if not r[3]]
print(f"useQuery 赋值点 {len(rows)}，未处理错误 {len(un)}")
for f, l, n, h in un:
    print(f"{f}:{l}  {n}")
```
