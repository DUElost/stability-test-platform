# ADR-0058 有效性验证记录：B1 / B2 证据盘点与 B3 验证方案

Status: implemented
Class: process

## Decision

**本 note 不修改 ADR-0058。** 它只做两件事：盘点 B1、B2 能证明什么、不能证明什么；
并在 B3 开始之前**预先登记**验证指标与证伪条件，避免事后挑选对自己有利的数据。
「登记的阈值」由规划者提议；**Owner 已于 2026-09-29 确认，阈值与 H1–H5 按 §Verification 所列登记**（本 note 因此转 implemented）。
登记生效不等于假设成立：假设是否成立要等 B3 与 4 周复查的数据。

### 1. 结论

B1 + B2 足以说明这套流程**能跑通**，并对其中几条机制给出了**正向信号**；
**不足以**证明 ADR-0058 正确。

### 2. 偏差声明

- 规划者、ADR 起草者、复盘记录者是同一个（Claude Code 云端工作面），没有第三方评估；
- ADR-0058 的 D1–D9 是从 B1 归纳出来的，**B1 是训练数据，不能再用来验证它**；
  B2 是第一个样本外检验，样本量 n = 1；
- 两批都是流程最容易见效的情形：同一缺陷形态的多个实例，且有现成参照实现。

### 6. 尚未被检验的部分

- **非同形态、无参照实现的问题**：两批都不是。

### 7. 混杂与局限

1. 没有对照组：不知道同样的问题走原流程会漏多少，也不知道 flash 模型没有方案时会差多少；
2. 没有结果指标：ADR §5 要求 B2 关单记录「退回次数及根因、复核前合入次数、激活到关单时长」，
   #3497 的关单评论里没有这几项，§3 是事后从评论与 PR 记录整理的；部署后的返工率、回归率、Owner 花费的时间**都没有**；
3. B2 修的是实例，没有加机械守卫（方案 §6 明确不抽公共组件；只有 G7 加了一条跨语言守卫），
   所以 D4「收口后不再回流」这部分要几周后才有数据；
4. #3502（v1.2）、#3490、#3492 三个 ADR 相关 PR 在一天内合入，说明文档本身也出现过
   需要外部复核才能发现的残留（ADR-0034 §2.6 漏改一句）。

### 8. 数据露出的缺口：规划者是最弱的一环

规划缺陷 B1 有 5 处、B2 在派单前又被方案复核找出 5 处，还有 1 处漏过（提示词失效）。
而 ADR-0058 只要求复核 **PR**，不要求复核**方案**；复核者的问题 A 只核对「是否符合方案」。
这是 n = 2 的观察，**不是结论**，也不据此修改 ADR；在 B3 里作为受控变量验证（见 H4）。

## Alternatives

- **直接宣布验证通过**：否。样本量、偏差、缺失指标都不允许；
- **立即在 ADR 里补「方案复核」条款**：否。证据只有 B2 一次，先受控验证；
- **回溯对比过去的单点修复批次做对照**：只作旁证（§5）。历史修复的问题、人员、时期都不可比，不作为判据；
- **规划者自己出评估结论**：否。规划者是被评估对象之一，B3 结束后的评估应由复核工作面独立执行，规划者只提供数据。

### 复查用扫描脚本（H1 基线）

在仓库根目录运行；它只数「赋值式 `useQuery` 里没有引用 `isError / error` 的调用点」，
**不判断失败时用户看到什么**——那一步需要人工逐个看渲染。

```python
import re, glob
rows = []
for f in sorted(glob.glob('frontend/src/**/*.tsx', recursive=True)):
    if '.test.' in f:
        continue
    s = open(f, encoding='utf-8').read()
    for m in re.finditer(r'const\s+(\{[^}]*\}|\w+)\s*=\s*useQuery\s*\(', s):
        lhs = m.group(1)
        if lhs.startswith('{'):
            handled = bool(re.search(r'\b(isError|error)\b', lhs))
        else:
            handled = bool(re.search(r'\b%s\.(isError|error|isLoadingError|status)\b' % re.escape(lhs), s))
        rows.append((f, s.count('\n', 0, m.start()) + 1, lhs.replace('\n', ' ')[:40], handled))
un = [r for r in rows if not r[3]]
print(f"useQuery 赋值点 {len(rows)}，未处理错误 {len(un)}")
for f, l, n, h in un:
    print(f"{f}:{l}  {n}")
```
