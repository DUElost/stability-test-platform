# ADR-0040 P2 切片②：分层收敛流——载荷拆分 + apply-resources 通道（#1975）

Status: implemented
Class: feature

## Decision

落地 ADR-0040 §5-3 P2 分层扩展主体（P2-B），身份与状态载体由 #1966（P2-A）
就位，本片切换**行为**：

1. **载荷拆分**：`_iter_payload_files(kind)` / `_build_tarball(kind)` /
   `_build_resources_tarball()`——code 载荷 = 代码树 + schema（~1MB，不再
   携带 resources/**）；resources 载荷 = `resources/**`（除 `mtbf/`）。
   两层与各自 digest 共享同一枚举（契约测试守护：层载荷 digest == 层身份）。
   #1951 的 `PROTECT_ONLY_PATHS=["resources/"]` 在 code 层 `rsync --delete`
   中保护主机大件不被清（§4.3 顺序兑现——这正是保护必须先行的原因）。
2. **两层收敛判定**：`plan_convergence(host, force)` 取代单层
   `evaluate_convergence`——code drift（vs `host.agent_artifact_digest`）与
   resources drift（vs `host.agent_resources_digest`）独立判定。**空集守卫**
   （P2-A 实证的硬约束）：控制面 resources 分区为空 → `resources_drift` 恒
   False 且 `resources_skipped_empty=True`——绝不下发空载荷把主机收敛到空。
   code 身份由 P1 全集迁移为 code 集（一次性多余全量部署，自愈，机制同 P1
   落地时）。
3. **wrapper 新子命令 `apply-resources --staged`**：rsync 范围限定
   `agent/resources/` 子树（--delete 不出界），`mtbf/` exclude+protect，
   `--safe-links`，staged 属主校验，降权执行——ADR-0037 模式完整复刻，
   §7-5 同 PR 回填。远端脚本对 wrapper 缺子命令的主机回退 legacy sudo
   rsync（同过滤，能力协商 #1942 同模式）。
4. **D4 restart 判据落地**：restart/deps/env/schema 全部收进 code 层 guard；
   resources 层独立收敛、**不重启**、不触碰 deps/env；两层 digest 在各层
   收敛成功后受控写入（code 探活通过后写；resources 应用成功后写，
   旧 wrapper 缺 `--kind` → WARN 跳过、legacy 主机走 sudo tee）。
5. **调用方**：UI/API 按 plan 驱动；`--direct` 双 tar 惰性构建（每层首次
   需要时才构建，P0 的整批一次构建语义按层延续）；precheck 治愈证据优先
   （code 恒全量 + resources 按真实 drift——force 只作用于 code）。

## Alternatives

- resources 层失败计入整体失败（当前语义）vs 只 WARN——resources 是正式
  收敛目标，静默降级会掩盖持续 drift；失败让下一轮重试（code 层已收敛则
  只重试 resources 层）。
- 空集守卫做成「跳过且告警」——告警留给 digest 不匹配；空集是合法形态
  （专项树本就无 resources），静默跳过即可，日志行已留。
- 把 restart 判据做成动态探测（如检查进程内缓存）——D4 表是显式声明，
  静态分层即完备，无动态必要。

## Revisit

- **Ansible 轨道归位**（P2 尾项）：`update_agent.yml` 职责收窄为首次安装 /
  resources 大件通道 / 灾难修复，并补其 ARTIFACT_DIGEST 写入（前置：其
  rsync 排除集与部署输入集契约对账）——另单。
- 灰度验收（ADR §6）：1 台 → 5 台 → 全量 + fleet `duration_ms` 复核 +
  no-op 稳态出现率，运维窗口内执行。
- code 身份迁移 bump：P1 主机 current（全集 digest）≠ 新 code desired →
  首轮多一次全量部署（自愈），已在 PR 注明。
