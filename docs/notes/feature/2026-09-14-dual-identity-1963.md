# ADR-0040 P2 切片①：身份分层——agent-code / host-resources 双 digest（#1963）

Status: implemented
Class: feature

## Decision

落地 ADR-0040 §5-3 P2 分层扩展的身份层（P2-A，加法片——**收敛行为零变更**）：

1. **双身份分区**：`collect_artifact_entries(kind)` 从共享载荷枚举
   （`host_updater._iter_payload_files`，tarball 与 digest 的同一契约源）分区——
   `full`（P1 全集，`evaluate_convergence` 判定语义不变）/ `code`（全集 −
   `resources/**`）/ `resources`（全集 ∩ `resources/**`，除 `mtbf/`）。
   控制面与 Agent 镜像同步；**分区并集 == 全集、互斥**由测试守护——P2-B
   载荷收缩（agent-code 载荷剔除 resources/）后，code 身份即载荷身份。
2. **第二 digest 文件**：wrapper `write-digest` 增 `--kind {code,resources}`
   （默认 code 向后兼容）→ `ARTIFACT_DIGEST` / `ARTIFACT_DIGEST_RESOURCES`；
   热更新远端脚本在 code digest 旁写 resources digest。`--kind` 能力探测失败
   （存量旧 wrapper）仅 WARN 跳过、不阻塞部署——代码收敛照旧，resources
   身份缺失只使 P2-B 对该主机多做一次全量 resources 部署（安全方向）。
3. **状态载体**：host 显式列 `agent_resources_digest`（迁移
   `i6j7k8l9m0n1`，additive nullable）；Agent `version_info.read_artifact_
   digest(kind)` 读第二文件；心跳逐拍上报（#1943 callable 语义同款）；
   端点落列（空值不覆盖）。

## Alternatives

- 直接切载荷 + 上分层流——身份与载荷语义迁移应原子（P2-B 一起），否则
  中间态的 digest 语义漂移会多触发一轮全量部署且无法归因。
- 第二文件改为单文件 JSON 双键——向后兼容差（P1 主机的单行文件读取要
  加解析分支）；双文件同名模式零解析成本。
- `--kind` 做成独立子命令——write-digest 同族语义（同校验、同目录、同
  原子写），参数化即可；ADR-0037 §D2 无新子命令。

## Verification

- `test_artifact_digest.py` 12 passed（新增分区 4 例）：code ∪ resources
  == full 且互斥、三身份互异且稳定、双侧镜像 parity 覆盖两 kind（schema
  extra 对齐）、resources 敏感性 + code 隔离（分层隔离的语义本体）。
- `test_agent_priv_write_digest.py` 6 passed（新增 3 例）：`--kind
  resources` 写第二文件、默认 code 向后兼容、未知 kind 拒绝。
- `test_host_updater.py` 31 passed（新增 2 例）：远端脚本写
  `ARTIFACT_DIGEST_RESOURCES`（wrapper `--kind` 能力探测失败仅 WARN +
  legacy tee 双路径）、空值时块被 `[ -n ]` 守护（运行时惰性）。
- 心跳端点 4 passed（resources 落列 + 空值不覆盖）。
- 迁移：一次性 PG16 容器空库链 `upgrade head` → 双列在位 → downgrade
  4c84155b7e59 列删 → 重升级；`check_schema_sync` exit 0（alembic 管理
  库口径；create_all 测试库跑它会撞 DuplicateTable——工具前提即
  alembic 管理，非本单回归）。
- `check:quick` 10 gates 全绿。

## Revisit

- **P2-B（分层收敛流）**：载荷拆分（agent-code 剔除 resources/）+
  `apply-resources` 通道（wrapper 新受控子命令，ADR-0037 联审）+ D4
  restart 判据 + 批量惰性构建——双身份载体本片已就位。
- **空输入集守卫（P2-B 硬约束，本单实证发现）**：`resources/` 大件不入
  git（gitignore + 带外布放），CI/新 worktree 树上 resources 分区恒空——
  分层流必须对「desired resources 为空」跳过收敛（绝不可把主机收敛到
  空——会清空 host 资源）。
- 存量机窗口：`--kind` 依赖新 wrapper；未升级机 resources digest 不落
  （WARN），P2-B 对其多一次全量 resources 部署（安全方向）。
