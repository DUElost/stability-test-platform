## Decision

按 [B5 #3653 当前方案 v1.3 §1.1/§3.5/§4.2 U3](https://github.com/DUElost/stability-test-platform/issues/3653)
实施 [U3 #3656](https://github.com/DUElost/stability-test-platform/issues/3656)。开工基线为
`origin/main@43dfc764a8881fabfed7979b3a40e6662f3c6120`，独立 worktree
`.wt/3656-plan-parameters-u3`，分支 `feat/3656-plan-parameters-u3`，Execution `B5-U3`，Harness `codex`，实施档位高阶。

- 已保存参数读取 `plans.parameterProjection`；新建或修改后的参数读取 `draftParameterProjection`。
  清单与 JSON 只展示当前请求身份对应的结果，effect cleanup 拒绝旧响应；失败不回退 raw。
  请求身份、脏比较和写入事实均留在内存，不进入 query key 或 DOM。
- 草稿标识为“L1草稿，未保存”。投影更新期间保留上一份安全元数据供编辑控件使用；
  用户主动输入保留本地文本与焦点，当前清单/JSON 等待新响应，旧异步响应不推进当前状态。
- Inspector 的参数值、说明与控件 schema 来自服务端投影。敏感项仅显示已设置/未设置，
  不渲染密码输入框或预填原始值。schema 尚未有取值的参数先添加空草稿，再由服务端给出安全元数据；
  新自由键也走相同投影链。
- raw 参数只用于现有内部保存事实。修改标量不替换其它参数；修改嵌套非敏感叶子复制原始兄弟。
  从继承对象进入编辑时，仅在用户操作时使用 U1 草稿浅合并 helper 保留原始对象事实，
  不把安全对象里的 null/掩码写回。保存协议、乐观锁与完整步骤构造保持既有路径。
- Plan 设置只读区复用 `ParameterProjectionList`，包含 watcher 与待派发因素。
  既有巡检时长/间隔控件保持操作规则，含义改取设置投影；其它设置编辑仍由 U6 承接。
  PlanCanvas/PlanSelectPhase 的 planTiming import 与整个过渡模块、旧测试已撤除。
- 编辑器 JSON 与脚本库展开区只显示 `safe_debug`。原始 default/schema 不再渲染。
  脚本库深链、用量失败空态与新版本空输入回归保留。新增只读区使窄屏内容增长，
  编辑器窄屏网格改用按内容分配的行，避免面板重叠；脚本库安全 JSON 限制视口宽度并支持横向滚动。

未修改共享 types/clients/公共组件、说明 JSON、后端、脚本发布单元、版本/pin 或部署范围。

## Alternatives

直接隐藏 raw 密码仍可能经 schema 默认、placeholder、自由键或 JSON 泄漏，因此不采用。
回写安全投影会丢失密码事实，因此不采用。保存态前端重算会绕过 L1 的服务端权威，因此不采用。
为了通过旧测试而恢复本地时长说明，会违背 planTiming 的终态出口，因此不采用。
