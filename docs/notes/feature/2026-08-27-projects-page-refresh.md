# 2026-08-27 — /projects 页面改版（设计评审问题①–⑤）

对应设计评审（本会话，依据 DOM 快照 + 代码审读 + 线上截图存档）确认的五个
问题：信息架构倒置、实现细节文案泄漏、原生 select 筛选、卡片层级弱、
远距操作反模式。属于方向 2「先 tokens 后逐页」路线的第一个样板间页面。

## 决定了什么

- **层级重排**：「项目」卡片区升级为第一内容区块（含 chip 筛选与状态徽标）；
  型号事实表降级为下方可折叠「型号映射」Card（默认展开，「映射所选型号(N)」
  按钮就近移入该区头部——勾选即见按钮，消灭远距操作）。
- **筛选重构**：四个原生 `<select>` 换成按字段分组的 chip 单选组（`aria-pressed`
  标注激活态、点选中值再点取消、每字段「全部」复位）；命中态改为带 × 的
  summary chips + 一键清空。未引入新依赖（纯 button + design tokens）。
- **文案收敛**：删除页头防御性副标题、"ADR-0029" 编号段落、EmptyState 里的
  HONOR-MLD 示例三处重复解释；替换为一句任务向描述 + 折叠区一行归属说明。
  「系统回填」概念保留在详情页 SEED 徽标处（唯一合理位置）。
- **卡片升级**：设备数上数字井（右对齐大字）、运行中显示 success 徽标
  `{n} 在跑`（空闲显示 outline「空闲」）、键盘可达（role=button/tabIndex/
  Enter+Space）与 focus-visible 环。

## 放弃的备选

| 备选 | 为什么放弃 |
|------|-----------|
| Radix Select 组件做 facet | 需新增依赖；值集合小（客户/平台各 ≤5），chips 更扫视友好 |
| 型号表移入独立 Tab | 路由成本 > 收益；折叠卡已满足降噪诉求且保留下方上下文 |
| 统计三卡改 KPI 行 | 属批次 B 一并处理（与抽屉联动改动大），避免一 PR 两主题 |
