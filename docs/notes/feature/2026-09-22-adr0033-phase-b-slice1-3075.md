# ADR-0033 Phase B 第一切片：tool_manifest + 确定性打包 + Agent tools_cache（#3075）

Status: implemented
Class: feature

## Decision

落地 #3075 第一切片（边界 = 该单 2026-09-22「实现前裁决」六条）：

- **唯一事实源** = Git `tool_manifest.json`（载体定 **JSON** 不采用 ADR 草案名 `tool_manifest.yaml`：
  PyYAML 不在 `backend/requirements.txt`，Agent/fleet 解释器不保证可用；stdlib 是零依赖硬约束）。
  条目字段恰好为分发六元组 `version/package_sha256/artifact/python/script/retired`（C5）；
  派生方向只允许 manifest → 发布 → 站点 `packages/manifest.json`（由打包器生成）→ Agent 拉取（C2）。
- **打包器** `tools/dev/package_tool_asset.py`：确定性 tar.gz（排序成员、mtime=0、uid/gid 归零、
  gzip mtime=0、GNU 格式无 PAX）；排除运行态面（`logs/ tmp/ result/ merge_result/ __pycache__ *.pyc`——
  真实 Start-Log-Scan 目录 866M 中 827M 是 logs，包后 6.1M/735 文件）。
- **门禁** `tools/dev/check_tool_manifest.py`（接 `run_gates` check:quick/check:pr + ci.yml lint job）：
  schema lint + append-only（删除/原地改写红；退役仅 `retired` 单向翻转；artifact 布局钉 C4）。
- **Agent 侧** `backend/agent/tool_cache.py`：拉取 + 整包 sha256 核验 + `.stp-verified` 幂等标记 +
  tar 成员越界硬拒（绝对路径/`..`/设备/FIFO；venv 式指向系统解释器的绝对软链按站点基座约定放行）；
  `scan_runner.configure` 优先级「显式传参 > 包面 > env」，任何失败原样回退 env（C3）；
  包引用经 `STP_AGENT_DEDUP_SCAN_PACKAGE_REF` 既有 env 推送链下发（C6：只切 Agent 侧，
  控制面 `STP_BACKEND_DEDUP_SCAN_*` 不动、出口记 #3075 后续切片）。
- **逃生阀默认关**：`STP_DEDUP_SCAN_PACKAGE_REF` 未设＝整链 no-op。合入本 PR 不改变任何现行为；
  发布样板包与 fleet 推送是合并后的独立运维动作。

## Alternatives

- **sha 语义复用 `Script.content_sha256`**：否（C1）——那是 entry-file 单文件 sha，工具包是整包 sha，
  同字段名混用即第二权威；新字段名 `package_sha256` 显式分离，脚本侧本窗口禁止 pin 包版本。
- **manifest 进 DB（script 表扩展行）**：否——`scan_script_root` 是「盘上目录自动登记」权威，
  外部工具不该反写进去（C2 派生方向）；且 ADR-0021 对齐门禁语义（盘 vs 库）会被污染。
- **Agent 直读 Git 仓库取 manifest**：否——Agent 分发面只有 hot-update 文件集，为读 manifest
  铺第二条仓库同步通道属过度；站点派生副本与包体同存储点，一次 NFS 读齐。
- **只打包源码、解释器留 env**：否——实测 `STP_DEDUP_SCAN_PYTHON` 指向工具自带 venv，
  不含 venv 的包不是完整资产身份，会造出「包一半、人肉一半」的第二过渡态。
- **首切片做退役工具**：否——退役 = manifest 里 `retired:true` 单行编辑，门禁已把守语义；
  工具化留待出现误用时再评。
