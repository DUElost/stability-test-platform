## 重点问题 F1–F7 逐条回答

- **F1 立项必要性**：成立。判据应是**已发生的歧义**（X1/X3），非 ADR 篇数。量化：四域内 ≥3 处「字面相同、限定词不同」→ 本基线 X1 即 3 处。
- **F2 是不是第 5 份平行权威**：取决于是否挂内容裁决权（A-02）。只挂归属权 + 表内一行一 owner + S6 体量约束 → 不会。与 storage-roles / execution-contract / DOC-MAP / AGENTS **无 supersede 关系**。
- **F3 判据可机读性**：表内唯一性 FP-free（N3）；锚须 S11/S5x 级强度；散文推导 owner 不可做；语义一致保留 owner 人工裁决（N4）。
- **F4 三处收口口径**：见 §X1–X3。
- **F5 F-1 窗口时序**：不能等（F1-03）；`AGENTS.md:15` 加终态指针；「S1x 语义一致」不可机读。
- **F6 多 Harness 适配**：`归属域` 按需驱动（A-03）；本表修改走共享元文件串行规则。
- **F7 验收可测性**：
  1. S15 自测红绿：同一概念两行 owner / 锚 0 处 / 锚 >1 处；
  2. ADR bump 且已写 `归属域` → 表须同 PR；
  3. （二期）新增「唯一权威|权威源」句式须命中表内行或豁免标记；扫描面含 `DOC-MAP` + `AGENTS`。
