## 4. 方案 A/B/C 选边理由

### 4.1 A — Accept-with-nits

**正收益判据（F1）**：`docs/adr` 内「唯一权威类」声明稀疏（本稿 13 行量级），但 **X1/X3 已是跨域交界真冲突**，且无任何一层保证「一个事实一个 owner」。#530 解决的是分层自洽（X2 型）；对 X1「同字面三限定词」没有标准化产物。⇒ **足以立一张窄表 + 门禁，不足以立全量 inventory**。

**须改再落（阻断）**：

1. **A-01（阻断）**：去掉「冲突时以本文为准」。否则索引被迫补写概念解释 → 第 5 份平行权威（N1）。与 `DOC-MAP.md:7-9`（冲突以代码与测试为准）及 `:114-121`（目录粒度权威/归档）分工：  
   - DOC-MAP = 目录粒度；  
   - semantic-ownership = **概念/关系粒度的 owner 索引**（Ownership Authority）；  
   - storage-roles / execution-contract / scan-upload-merge-contract / AGENTS 硬不变量 = Domain Authority；  
   - 本表 **不**获得内容 supersede 权。
2. **A-02（阻断）**：S15「锚不可解析 → 红，**复用 S2**」不成立。S2（`check_governance_surface.py:10,:147-162`）只验 markdown **相对链接文件存在**，跳过 `#` 锚与代码示例，**从不解析 `path:line`**。落点：S15 自写解析器；锚 = **文件 + 结构化定位（节标题 / 表行 key）**，需要钉文字时用 **S11 式文本模式（命中 0 或 >1 皆红）**；行号可做人读跳转，**不进判据**（弱行号 = 假绿，同 S5x/#2445 教训）。
3. **A-03（建议→准阻断若一次扫全库）**：S15 判据①只对 **monitored 行**（N3）；判据③「ADR bump 涉归属域 → 表同 PR」仅当该 ADR 头部**已写** `归属域：` 时生效（字段驱动补齐，忌一次 48 篇全红）。

**可并入 A 的 B 要素**：①复议触发器列（写清触发条件）；②五问决策树若采用，落点在 `ai_work.py declare` §3.4 查重 / issue 模板——**须另开 ADR-0034 域单**，不搭本单（本单不做 Accepted 裁决）。

### 4.2 B — Needs-revision

全量 Semantic Inventory 与「13 处声明 / 3 处真冲突」不成比例；且易与 DOC-MAP「权威 vs 归档」正面重复。保留其锐利判据句（exactly one semantic owner）作为 **A 表的设计目标陈述**即可，不要 Step-1 抽名词。

### 4.3 C — Needs-revision

X3 在提案 / 台账 / ADR-0027 三处同主题归属互斥；X1 在 0021 与 0033 之间用同一「唯一权威」字面。继续逐对收口会重复支付「每次发现 → 每次人工记一笔」的成本，且无机械防复发。C 只适合纯分层澄清（X2）；对跨域字面冲突不够。

## 5. F1–F7 逐条

### F1 立项必要性 — **建议：立 A（收窄后）**

量化：权威类声明稀疏，真冲突少但**全部落在跨域交界**。ADR-0011:32「上位/下位、不构成平行权威源」适合**已识别的一对**就地写清（如 0011↔0036）；对「评审方无法判定该信哪一条」的 **X1 字面冲突**不够——需要可机读的 owner 行。

### F2 会否长成第 5 份平行权威 — **阻断风险存在，可用 N1 消掉**

### F3 判据可机读性 — **表内可机读；全库散文不可**

| 判据 | 假阳性 / 假绿面 | 处置 |
|---|---|---|
| 同一概念 ≥2 owner | 若扫散文：分层权威（X2）被误判 | **仅表内**（N3）→ FP-free |
| 锚可解析 | 裸 `file:line` 行漂假绿；书写变体 | 结构化锚 + 文本唯一性（A-02） |
| ADR bump → 表同 PR | 未写归属域字段则全红；引用他文行误伤 | 字段驱动；行级豁免标记（学 S14 #2249） |

做不到「从散文推导 owner」就**不要做**——降级为人工清单的代价是复发，A+S15 表内门禁已够第一版。

### F4 收口口径 — 见 §2.1–2.3 单行建议

### F5 F-1 窗口时序 — **建议：先纠事实，再指针，不做语义 S1x**

1. 今日该句在 **总原则** 不在硬不变量 → S11（`:270-282` 共 11 锚）**完全不覆盖**；ADR-0039:16 亦误称为硬不变量。

### F7 验收可测性 — **建议改写**

「出现新双标时 S15 必红」若 S15 **只看表**则做不到。可测验收：

1. X1/X2/X3（及选定边）各收敛为表内 **一行**，且锚（结构化）可解析且唯一；
