# 激活后的分层验收

- **状态**：Living v1.0（2026-10-26，自 `batch-planning.md` v1.3 §6 迁出）
- **触发**：批次进入激活与验收
- **权威**：ADR-0058 D9；激活闸门见 [`role-cards.md`](../role-cards.md) 与 `batch-planning.md` §6

- 验收按 L0–L3 分层（ADR-0058 D9）。L0 / L1 用只读查询，L2 用 Owner 授权的金丝雀 PlanRun（指定设备、最短配置、
  只调时长与次数），L3 以单元测试与复核者的独立负向证据为准。
- L2 至少覆盖一次「已有状态」前置用例（如设备上已存在续跑状态），干净设备测不到这类旧缺陷。
- 验收中发现的改动前已存在的缺陷另立 issue，不阻塞本批关单。
