# 独立负向证据

- **状态**：Living v1.0（2026-10-26，自 `batch-review.md` v1.2 §4 原样迁出）
- **触发**：复核者给出结论之前
- **权威**：ADR-0058 D8「复核者只回答两问」；复核者必须提供独立负向证据，本文只给做法

优先用**可逆变异验证**：临时回退修复点，确认相关测试变红，再恢复，把结果写进评论。至少对每个核心修复点做一次。

变异不适用或风险过高时，写明原因并给出等价证据：

| 对象 | 等价证据 |
|---|---|
| 配置契约 / 模板 | 篡改 fixture 或 pin 后守卫应红 |
| 部署 / 激活步骤 | dry-run，或与旧基线对照 |
| 文档流程 | 事实对账（引用的数字、链接、状态逐条核实） |

判定「现有门禁与测试拦不住」之前，必须在变异副本上运行与该语义相关的全部 required 测试（不只本单元的守卫），
把命令和结果写进评论（ADR-0058 D11 第 2 条）。
